<h2><span class="lang-en" lang="en">Try it</span><span class="lang-it" lang="it">Provalo</span></h2>
<p><span class="lang-en" lang="en">Install the package with <code>npm install evalanche</code>, or start the MCP server with <code>npx evalanche-mcp</code>. The default MCP transport is stdio; HTTP mode requires an explicit bearer token. Authenticated Polymarket actions use the official <code>polymarket</code> CLI.</span><span class="lang-it" lang="it">Installa il pacchetto con <code>npm install evalanche</code> oppure avvia il server MCP con <code>npx evalanche-mcp</code>. Il trasporto MCP predefinito è stdio; la modalità HTTP richiede un bearer token esplicito. Le azioni autenticate su Polymarket usano la CLI ufficiale <code>polymarket</code>.</span></p>
