<p><span class="lang-en" lang="en">Ideas is a local source preview for macOS. Start with the <a href="/projects/ideas/">project page and download</a>. The README in the archive contains the setup commands. Installation requires macOS 14+, Node 22.13+, Xcode, XcodeGen and Codex with local plugin support.</span><span class="lang-it" lang="it">Ideas è un’anteprima del codice da eseguire localmente su macOS. Parti dalla <a href="/projects/ideas/">pagina del progetto e dal download</a>. Il README nell’archivio contiene i comandi di configurazione. Servono macOS 14+, Node 22.13+, Xcode, XcodeGen e Codex con supporto ai plugin locali.</span></p>

<h2><span class="lang-en" lang="en">Calendar and Reminders</span><span class="lang-it" lang="it">Calendario e Promemoria</span></h2>
<p><span class="lang-en" lang="en">Build the Ideas Sources connector and install the background service before opening the plugin. In Ideas, select Connect Mac sources and allow the requested macOS permissions. If access was denied, review Ideas Sources under System Settings → Privacy &amp; Security → Calendars and Reminders. Refresh from Ideas and inspect its connection status and timestamps. An unavailable source is not an empty calendar.</span><span class="lang-it" lang="it">Compila il connettore Ideas Sources e installa il servizio prima di aprire il plugin. In Ideas seleziona Connect Mac sources e consenti i permessi richiesti da macOS. Se l’accesso è stato negato, controlla Ideas Sources in Impostazioni di Sistema → Privacy e sicurezza → Calendari e Promemoria. Aggiorna da Ideas e controlla stato della connessione e orari di aggiornamento. Una fonte non disponibile non equivale a un calendario vuoto.</span></p>
<p><span class="lang-en" lang="en">The Calendar window runs from yesterday through the next seven days. Reminders include incomplete items without a due date. Refresh runs every five minutes and when EventKit reports changes. The connector reads sources; it does not edit events or complete reminders.</span><span class="lang-it" lang="it">La finestra del Calendario va da ieri ai prossimi sette giorni. I Promemoria comprendono gli elementi incompleti senza scadenza. L’aggiornamento avviene ogni cinque minuti e quando EventKit segnala cambiamenti. Il connettore legge le fonti; non modifica gli eventi e non completa i promemoria.</span></p>

<h2><span class="lang-en" lang="en">The page will not open</span><span class="lang-it" lang="it">La pagina non si apre</span></h2>
<p><span class="lang-en" lang="en">Check that Node is installed, the local background service is running, and the plugin is enabled. Reopen Ideas after installation. Its launcher supports the standard Apple Silicon and Intel Homebrew Node locations, with a PATH fallback. If the service folder was moved, reinstall its LaunchAgent from the new location. Do not share connection.json or its tokens.</span><span class="lang-it" lang="it">Controlla che Node sia installato, che il servizio locale sia in esecuzione e che il plugin sia abilitato. Riapri Ideas dopo l’installazione. Il launcher supporta i percorsi Homebrew standard per Node su Apple Silicon e Intel, con un fallback sul PATH. Se hai spostato la cartella del servizio, reinstalla il LaunchAgent dal nuovo percorso. Non condividere connection.json o i suoi token.</span></p>

<h2><span class="lang-en" lang="en">Chat creation and other devices</span><span class="lang-it" lang="it">Creazione delle chat e altri dispositivi</span></h2>
<p><span class="lang-en" lang="en">Choose Create chat on a specific item. Capture and refresh do not authorize automatic chats. If your host lacks native Codex chat tools, Ideas can prepare context but cannot create a native chat there. If a previous creation is uncertain, reconcile the existing request before retrying.</span><span class="lang-it" lang="it">Seleziona Create chat su un elemento preciso. Cattura e aggiornamento non autorizzano chat automatiche. Se l’host non dispone dei tool nativi di Codex, Ideas può preparare il contesto ma non creare lì una chat nativa. Se una creazione precedente ha un esito incerto, verifica la richiesta esistente prima di riprovare.</span></p>
<p><span class="lang-en" lang="en">Mobile companion and Share-extension sources are included, but require your own Apple signing and provisioning for device installation. A phone or tablet must be explicitly paired with your own computer. Mobile in-app availability has not been established. The project is not currently listed in OpenAI’s public directory.</span><span class="lang-it" lang="it">Sono inclusi i sorgenti del companion mobile e dell’estensione Condividi, ma l’installazione sui dispositivi richiede firma e provisioning Apple propri. Un telefono o tablet deve essere associato esplicitamente al tuo computer. La disponibilità in-app su mobile non è ancora verificata. Il progetto non è attualmente nella directory pubblica di OpenAI.</span></p>
