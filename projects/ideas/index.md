<h2><span class="lang-en" lang="en">Run it on your own Mac</span><span class="lang-it" lang="it">Sul tuo Mac</span></h2>
<p><span class="lang-en" lang="en">Ideas runs its inbox and MCP server on the computer of the person installing it. Each installation has its own local database, credentials and macOS Calendar and Reminders permissions. The desktop plugin connects to that local service; this website hosts the project information and source download.</span><span class="lang-it" lang="it">Ideas esegue la propria inbox e il server MCP sul computer di chi lo installa. Ogni installazione ha un database locale, credenziali proprie e permessi macOS per Calendario e Promemoria. Il plugin desktop si collega a quel servizio locale; questo sito ospita le informazioni sul progetto e il codice da scaricare.</span></p>

<p><span class="lang-en" lang="en">The source preview requires macOS 14 or later, Node 22.13 or later, Xcode, XcodeGen and Codex desktop/CLI with local plugin support. Follow the README to build the Ideas Sources connector, install the local background service and add the plugin. Keep the extracted folder in a permanent location: the service runs from that folder.</span><span class="lang-it" lang="it">L’anteprima richiede macOS 14 o successivo, Node 22.13 o successivo, Xcode, XcodeGen e Codex desktop/CLI con supporto ai plugin locali. Segui il README per compilare il connettore Ideas Sources, installare il servizio locale e aggiungere il plugin. Conserva la cartella estratta in un percorso stabile: il servizio viene eseguito da lì.</span></p>

<h2><span class="lang-en" lang="en">What works, and what is still pending</span><span class="lang-it" lang="it">Cosa funziona e cosa resta da verificare</span></h2>
<p><span class="lang-en" lang="en">The local release has an Ideas sidebar page using OpenAI’s MCP App styles, with source tabs, search, details and capture. Calendar and incomplete Reminders were read on the development Mac through EventKit. Twelve automated tests cover capture, retries, source freshness, explicit chat claims, authentication and MCP responses. Saving an idea or refreshing sources never creates a chat automatically; native chat creation also requires Codex’s native chat tools.</span><span class="lang-it" lang="it">La versione locale ha una pagina Ideas nella sidebar, con gli stili MCP App di OpenAI, schede per fonte, ricerca, dettagli e cattura. Calendario e Promemoria incompleti sono stati letti sul Mac di sviluppo tramite EventKit. Dodici test automatici coprono cattura, tentativi ripetuti, aggiornamento delle fonti, selezione esplicita della chat, autenticazione e risposte MCP. Salvare un’idea o aggiornare le fonti non crea automaticamente una chat; la creazione nativa richiede anche i tool per le chat di Codex.</span></p>
<p><span class="lang-en" lang="en">This is a source preview, not a signed or notarized one-click installer. A clean installation on another computer, physical mobile Share receivers and native chat creation from an actual selected item remain unverified. Phone and tablet layouts were checked with sample records; installing the desktop plugin does not make it available automatically on mobile.</span><span class="lang-it" lang="it">È un’anteprima del codice, non un installer firmato o notarizzato da avviare con un clic. Restano da verificare un’installazione pulita su un altro computer, le estensioni Condividi su dispositivi fisici e la creazione nativa di una chat da un elemento selezionato. I layout per telefono e tablet sono stati controllati con dati di esempio; installare il plugin desktop non lo rende automaticamente disponibile su mobile.</span></p>
<p><span class="lang-en" lang="en">The OpenAI public-directory release has not been uploaded, submitted or approved. The standard MCP submission flow currently requires a public HTTPS endpoint; local MCP distribution needs confirmation from OpenAI. The intended architecture remains one local inbox per installer.</span><span class="lang-it" lang="it">La versione per la directory pubblica di OpenAI non è stata caricata, inviata o approvata. Il flusso standard per gli MCP richiede oggi un endpoint HTTPS pubblico; la distribuzione di un MCP locale va confermata con OpenAI. L’architettura prevista resta un’inbox locale per ogni installazione.</span></p>
